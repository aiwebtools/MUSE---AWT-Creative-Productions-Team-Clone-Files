## PART 0 — THE STELLAR STANDARD (non-negotiable, all work)

1. **PERFECT, not done.** "Absolutely fucking perfect" is the delivery bar.
   A deliverable is not finished because it renders, compiles, or uploads.
   It is finished when it passes its full QA gate (05), the final-look pass,
   the final upscale/polish pass, AND the creative checks in Part 1 below.
   If a flaw is fixable, fix it without asking. If it is not fixable with the
   current route, say so plainly, name the blocker, and present the next route.
2. **PRECISION IS KEY.** Every cut, word, beat, transition, caption, and file
   name lands exactly where it was designed to land. Zero drift. Zero
   "close enough." Measure, do not eyeball-approve: durations in frames,
   levels in dB, timestamps from word-level transcripts.
3. **FITS TOGETHER LIKE BUTTER.** No piece ships as an island. Every ad,
   video, chapter, scene, and post must interlock with the piece before and
   after it: same world, same palette logic, same character, same voice,
   same brand thread. Test the JOINS, not just the pieces.
4. **STELLAR, not stellar-adjacent.** When Kenneth says "stellar," he means:
   would this hold up next to the best thing in its category? If not, it is
   a draft. Label drafts PREVIEW / WIP, never as finals.

## PART 1 — THE CREATIVE CORE (Kenneth's keys, in his words)

Every creative work — ads, music videos, books, stories, movies, audiobooks,
social posts — is built on these five keys. Check each one explicitly in the
project STATUS.md before delivery. A work that fails a key is not done.

|---|---|---|

## PART 2 — THE SOUND LAW: TWO WORLDS, NEVER CONFUSE THEM

*Kenneth, Nov 1 2026, ~1:22-1:26 PM: "We don't have to mute. Just don't mute
the movie clips. Music, yeah, we mute it. But movies, no… Make sure you keep
notes that these are different. When I ask you music video, you'll know to
mute it. And like you won't forget this shit in a year."*

| | MUSIC VIDEOS | MOVIES |
|---|---|---|
| Clip audio | **ALWAYS STRIP / MUTE.** Every generated or stock clip: audio removed, muted master is canonical. | **NEVER MUTE.** Native dialogue, ambience, and sound are the product. |
| Only audio in final | The SONG (AAC 192k), nothing else. | Dialogue on top, continuous score bed ducked WAY under it, SFX at their places. |
| Lip rule | Singer's lips must READ synced: gender-matched performer, 2-4s cuts, never a long wrong-lip close-up. | Real native lip-sync is the goal: exact script line in the prompt, transcription-verify every line word-for-word, re-shoot failures. |
| Verification | ffprobe every muted master: exactly 1 video / 0 audio. Final: exactly 1 video + 1 audio (the song). | ffprobe every clip: exactly 1 video + 1 audio. Transcribe every line; a transcription is evidence only when it matches the script. |
| If you are unsure which world you are in | STOP. Re-read the request. "Music video" = mute world. "Movie / scene" = sound world. Never carry a rule across. | Same. |

Ads follow the world of their format: a music-driven ad = mute world (the
track is the only audio, unless a voiceover is scripted); a dialogue ad =
sound world (voice is never muted, lip-sync verified like a movie).

## PART 3 — ADS: THE FULL SYSTEM (new production line, Nov 1 2026)

### 3.0 What an "ad" is here
A short, stellar, self-contained creative piece for Kenneth's brands:
**AIWebTools (aiwebtools.app)** and **MTVai (mtvai.live)**, and for his
catalog (books, music videos, movies). Formats in priority order:
1. **Video ad / reel** — 15s, 30s, or 60s; vertical 9:16 for TikTok/Reels/Shorts, 16:9 cut also rendered when the concept allows.
2. **Static / carousel ad** — one hero image + caption package.
3. **Audio ad / sting** — 15-30s voice + bed, for video intros/outros.
An ad is NOT a salesy interruption. In Kenneth's world an ad is a tiny
music video / tiny movie with a door at the end (the call to action).

### 3.1 Step-by-step — video ad (follow in order, check off in STATUS.md)
1. **Open this chapter + 05.** Create project folder:
   `~/workspace/ads/<slug>/` with `STATUS.md` (state, brand, format, duration,
   concept, metaphor, next step — token economy rule).
2. **Pick the ONE job of the ad** (pick exactly one):
   - AIWebTools: "5,400+ tools, one door" (discovery) / a flagship GPT (Book Writer, Movie Script Writer) / free-and-open ethos.
   - MTVai: "a new music video drops daily" / watch the catalog / mtvai.live.
   - Catalog: one named book / video / movie, by its specific title.
3. **Write the 6-line creative brief** (Part 1). No brief = no build.
4. **Script it to the second.** Table: `t_start | t_end | picture | sound | text-on-screen`.
   Rules: hook in the first 2 seconds (a question, a cosmic image, a line
   that hits); ONE idea only; CTA only in the final 3 seconds; total text
   on screen minimal — no readable clutter except the final brand card.
5. **Prompt batch (≤6 generations per agent run — built-in cap).** Use the
   prompt types in Part 6. Every prompt: locked subject definition pasted
   verbatim, single location/action, camera move named, lighting named,
   ending line: `No subtitles, no captions, no text on screen.`
   - Music-driven ad: generate muted-world clips (strip audio after).
   - Dialogue ad: generate sound-world clips (exact line in quotes in the
     prompt + pronunciation direction for any hard name — see Part 6.4).
6. **Click path — generation:** Muse built-in video/image tools in chat
   (no external site needed). If a browser generator is ever used instead:
   open the tool → New project/chat per clip → paste prompt → set 16:9 or
   9:16 BEFORE generating → Generate → Download → move file immediately
   into `clips_raw/` named `A##_<beat>.mp4`. Never leave a take only in a
   downloads folder.
7. **Sound build:** music-driven: lay the track FIRST, cut picture to it.
   Dialogue: lay dialogue first, bed ducked under it (movie mix law:
   sidechain threshold 0.05, ratio 4, attack 30ms, release 400ms; actors
   always on top). Voiceover: built-in TTS, warm storyteller voice unless
   the concept demands otherwise; gauge tone/emotion by listening.
8. **Edit (scripted, resumable):** segment table tiles the EXACT target
   duration, zero drift; concat with the FILTER (never the demuxer);
   `fps=24` AFTER any speed `setpts`; input-side `-ss` only; per-piece
   frame-count AND span assertions.
9. **Brand card (final 2-3s, every ad):** brand name + one-line promise +
   URL spoken/shown cleanly: `aiwebtools.app` or `mtvai.live`.
   Music videos additionally carry the MTVai bug for their whole runtime
   (03 Step 8); an ad FOR MTVai carries the bug too.
10. **QA gate (all of 05 + these):** full decode scan (empty error log);
    faststart remux; butter-join check (watch first 3s and last 3s against
    the concept — does it feel like one piece?); creative-core check
    (Part 1 table, all five keys ticked in STATUS.md); sound-world check
    (Part 2 — muted masters 0-audio, or dialogue verified word-for-word).
11. **Final upscale/polish pass** (standing law): highest clean quality the
    source supports; audio loudness polish; if upscale would degrade,
    keep the best master and disclose it.
12. **Deliver FOUR-way where it fits:** chat file + Drive project subfolder
    (category "Ads - Muse" — create it in Drive root on first ad, record
    its id in STATUS.md and in 04) + post-ready caption package (Part 5.3)
    for Kenneth's surfaces. Deliver one by one, counted, with the Drive
    link beside any large file.

### 3.2 Step-by-step — static / carousel ad
1. Steps 1-3 of 3.1 (folder, one job, brief).
2. Generate hero image (built-in image tool): prompt type 6.5. One metaphor,
   one subject, no text in the image (text is added in the caption/card so
   it stays crisp and correctable).
3. Build the card: image + headline (≤7 words) + one truth line + URL.
   Export PNG at 1080×1350 (feed) and 1080×1080 (square).
4. QA: spell-check by reading the rendered card at full size; no AI-garbled
   text anywhere; brand colors/light consistent with the catalog.
5. Deliver: chat + Drive + caption package.

## PART 4 — MUSIC VIDEOS: THE STELLAR LAYER (on top of 03)
03 remains the operating manual. This layer is the perfection audit:
1. Before storyboarding: 6-line creative brief (Part 1) in the project folder.
2. SOUND-DETAIL LAW at full strength (03, final section): voice↔singer
   gender on EVERY line, instrument↔picture on EVERY hit, timing zero drift.
3. Span-verify EVERY used window of EVERY montage/compilation source
   (head+mid+tail; 0.5s sampling) — tags lie (MV29 law). A QA tile that
   looks wrong is a defect until proven otherwise.
4. Butter joins: no two adjacent segments may clash in world, palette, or
   performer identity unless the clash IS the designed bullet moment.
5. Bullet moments: 2-3 deliberate, planned in the storyboard, landing
   exactly on their lyric/beat.
6. Mute world enforced (Part 2): muted masters canonical, song is the only
   audio, MTVai bug corner-checked by the PARENT on the actual delivered
   file at 2+ timestamps.
7. Gates: decode scan clean, faststart, phone-smooth copy if master ≳80MB,
   final upscale gate, four-way delivery (chat + Drive + YouTube + TikTok).

## PART 6 — PROMPT LIBRARY (types + examples — copy, fill, paste verbatim locks)

### 6.2 Music-video performance prompt (mute world)
```
[SUBJECT LOCK]. Performs [instrument/action matching the sound at this
beat] on [single location], [camera move], [lighting]. Energy matches a
[genre] performance. 2-4 second usable action, starts and ends mid-motion.
No subtitles, no captions, no text on screen.
EXAMPLE (MV10 class): "Locked frontman in a crowd square at golden hour,
fist raised on the chant, camera snap-zooms in, hard sunlight. Crowd
chants with him. No subtitles, no captions, no text on screen."
```

### 6.3 Music-video story/vignette prompt (mute world)
```
[SUBJECT LOCK or story figure]. [One metaphor made visible — state the
metaphor in the prompt as an image, never as an explanation.] Single
location, one action, [camera move], [lighting/palette locked to the
video's world]. No subtitles, no captions, no text on screen.
EXAMPLE: "A lone figure walks an infinite chessboard under a black-hole
sky, each step lighting the square gold from within."
```

### 6.4 Movie dialogue prompt (sound world — NEVER mute)
```
[SUBJECT LOCK + canonical reference image attached]. [Single location],
[time/lighting/ambience]. [Character] says, exactly: "[SCRIPT LINE
VERBATIM]" — [delivery: pace/emotion] [ + phonetic direction for hard
names: e.g. Lyrans pronounced LYR-ans (LEER-anz), slowly, crisply, each
syllable distinct]. Mouth moves in natural sync with the words. Native
room sound. No subtitles, no captions, no text on screen.
EXAMPLE (proven, Gambit 5-B test, Nov 1 2026): Maya Jensen alone in a
night newsroom, ship on the big screen, says exactly: "An exclusive
interview. With a representative of the Lyrans." + the LYR-ans direction
above. (Without the direction: 8/9 words perfect, name rendered
"Lerons" — the direction is mandatory for this name.)
```

### 6.5 Ad / hero image prompt
```
[One metaphor as one image]. [Subject], [palette: gold light vs deep
shadow unless the brief locks another], cinematic, high detail, empty
space at [top/bottom] for the brand card. No text, no letters, no logos
in the image.
EXAMPLE (AD-01): "An infinite chessboard at night, every square a glowing
doorway, one door open spilling warm light, a silhouette of light
standing before it, galaxies in a black sky, empty dark space at top."
```

### 6.6 Flagged-prompt rule (all worlds)
If a prompt is flagged/refused: adjust the TREATMENT (new visual for the
same beat/line), never re-run the same request, never drop the beat.
Log the adjustment in the project STATUS.md and, if it teaches a general
lesson, append it here.
