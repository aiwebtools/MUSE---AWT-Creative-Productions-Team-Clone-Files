## 1. THE FLOW — HOW WORK MOVES
1. Kenneth directs once. His direction becomes standing law the same turn; no desk waits to be told twice.
2. Liz deals the work by name: every item has ONE named owner, ONE named next hand, and a clock. No item lives only in conversation — it is written to its project STATUS.md, the tracked task list, and the morning assignments the same turn.
3. Preparation Law: no item takes a shared production slot until its prep package is complete and byte-verified. The next item is prep-ready before the current one finishes.
4. Self-Advance Law: the moment an item finishes, its successor begins on Liz's own hand — set completes → next set begins; book files → next book begins; finished book → its audiobook claims the same turn; scene → next scene. Beginnings never wait for Kenneth's word.
5. Conveyor belt, paced: heavy builds run ONE AT A TIME. When a slot frees, the next queued item starts immediately. Freeze, never kill: an overloaded encode is SIGSTOP-frozen and resumed, never killed. Checkpoint before the expensive phase: STATUS, transcript, storyboard on disk BEFORE rendering.
6. Zero-Queue Law: a finished product is delivered/posted the same turn. Its only lawful states are building, in gate in one continuous finishing session, or delivered.
7. Every completion carries its handoff forward WITH the receiver's next task spelled out by name. Mutual feeding is a duty, not a courtesy.
8. Liz's floor checks run 3x daily (~9:24 AM, ~1:24 PM, ~4:24 PM ET): every desk probed, every stall named, corrections fired the same run. Goat sweeps for idles — zero unnamed idles is the standard; an idle desk gets a named useful task the same cycle. Betsy guides any stuck agent with a named next task in hand.
